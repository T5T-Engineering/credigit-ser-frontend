# credigit-ser-frontend

Core web application for **Smart Enterprise Risk 360°** (Credigit Analytical Limited).

- All UI components come from the shared library `@credigit/web-ui`
  ([credigit-ser-web-component](https://github.com/T5T-Engineering/credigit-ser-web-component)).
  This app contains pages, data access and composition only — no UI components of its own.
- Branding (colours, fonts, logo) comes from the Credigit brand kit via the library and can be changed at runtime.
- Product scope: see the PRD in [credigit-ser-claude-works](https://github.com/T5T-Engineering/credigit-ser-claude-works).

## Branches

`develop` (all work lands here) → `test` → `uat` → `staging` → `production`.
